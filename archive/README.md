# Historical source archive

These files document the original Result1–Result6 analyses and manuscript-production
history. They are excluded from `run.py` and do not reproduce the revised claims.
Local drive/server paths were converted to environment variables; algorithms and
historical comments were retained. Some scripts require original interactive
workspace objects, old models, external motif databases or proprietary application
installations. The complete original source identities are in the inventory.

The mixed R/Python .sh file is preserved as text and split into language-specific
08a/08b files. A high/low DSE expression comparison in that historical workflow
must not be described as a gene knockout. Current network perturbations are in
`code/08_virtual_KO.R`.

Old draft response builders and the one-time denominator migration are historical
tools. Do not use them to replace the completed current revision or rerun them as
part of a fresh analysis. Document tools are retained for source completeness only.
